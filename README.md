# My Own `pwd`

A reimplementation of the Unix [`pwd`](https://man7.org/linux/man-pages/man1/pwd.1.html) utility.

## About

This project is part of the **My Own Utilities** collection.

It is developed for educational purposes and personal use, focusing on learning systems programming and Unix-like tool design.

It is not intended to be a drop-in replacement for the original utility and may intentionally differ in behavior, features, or implementation details.

This is an independent implementation based on Unix documentation and man pages. It does not use GNU coreutils source code.
